## 🎙️ VoiceTrace

**Voice-first marketplace powered by LLMs, semantic search and RAG.**

VoiceTrace explores how voice interfaces and AI can simplify digital interaction for producers and buyers.

### AI pipeline

```text
Voice
  ↓
Speech-to-Text
  ↓
Language / Derja Normalization
  ↓
LLM Structured NLU
  ↓
Pydantic Validation
  ↓
Dialogue State
  ↓
Backend Tools
  ↓
Database
```

### Key technologies

`LLMs` `RAG` `Speech-to-Text` `TTS` `pgvector` `PostGIS` `FastAPI` `React`

The system follows a simple principle:

> **AI understands the user. Deterministic backend services control the data.**
